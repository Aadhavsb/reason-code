04 / Explanation check

Evidence verdict

Current API boundary

Not computed by /decisions

The decision endpoint currently returns a decision, score, source, policy version, and attributions. It does not return a reason-code mapping, an explanation, a closed evidence set, or a faithfulness verdict.

Why this is shown as unavailable

The repository contains deterministic explanation and evidence-grading utilities, but they are not wired into the decision API. This UI does not infer a reason code or manufacture a verdict from the visible factors.

  • No HMDA dataset is loaded or represented here.
  • No calibrated-model performance or approval metric is displayed.
  • No external service, hosted asset, or LLM request is made.
Walkthrough boundary: this page is a local demo interface. The repository's CLI and evaluation utilities remain separate from this UI.
